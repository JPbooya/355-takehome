# Application Tracker
React app that tracks job applications and shows a summary of how many applications are in each status and lists every application too newest first wtih company name, role, status, date applied, source and notes.

## Run it
npm install: Installs the project dependencies.
npm run dev: runs and opens the server with localhost link.
